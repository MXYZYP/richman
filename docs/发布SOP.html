大富翁联机游戏 · 发布标准操作流程（SOP）

傻瓜式 · 从"本地内网穿透"到"云端 7×24 联机 + Android / 鸿蒙双端上架" · 无经验人员也可照做
⚠ 发布前必读（一票否决级事实）：当前版本的服务器没有磁盘存档——所有房间和牌局都只存在服务器进程的内存里。
  • 服务器重启 / 崩溃 / 更新 / 容器重建，进行中的牌局会全部丢失，玩家需要重新建房或加入。
  • 这不是部署问题，是代码现状。云端迁移本身不受影响，但不要向玩家承诺"服务器重启不丢局"。
  • 若上架后不能接受这点，需先补存档持久化（见 docs/云端迁移方案.html "plan/03 §7"），再发布。
本文件能让你独立完成什么：① 把服务端部署到云服务器实现全天候联机；② 打包出 Android APK；③ 打包出 HarmonyOS（鸿蒙）APP；④ 把鸿蒙 APP 上架到华为应用市场。每一步都给出"点哪里 / 敲什么 / 看到什么 / 错了怎么办"。涉及账号实名认证与平台提交的部分，必须你本人操作（我无法代你登录华为/支付/提交审核），但工程与清单已备齐。

0. 整体发布顺序（先做什么后做什么）

顺序不能乱：没有云端地址，App 联机就没有目标。建议严格按下表从左到右推进。

① 服务端上云拿到公网地址 https://…
→
② 填地址把云地址写进 App 配置（云端模式）
→
③ 打 Android出 APK
→
④ 打鸿蒙出 APP
⑤ 上架鸿蒙华为市场（需本人账号）
→
⑥ 上架安卓应用宝/Google Play（可选）
→
⑦ 验证真机联机对战
→
⑧ 维护云端模式更新即生效
两种加载模式，发布前先决定：
  • 云端模式（推荐）：App 启动后从你的云地址加载游戏。服务端一更新，所有玩家无需发版即最新。代价：玩家联机必须联网。
  • 离线模式：把构建好的网页打包进 App，玩家不联网也能打开首页；但联机对战仍需联网，且每次改游戏都要重新打包上架。
本 SOP 默认按云端模式讲解（最省后续维护）。离线模式的差异会在对应步骤标注。

1. 发布前准备清单

不需要一次买齐，按发布顺序用到再准备即可。打勾表示"已具备"：

  • 本机已装 Node.js 20+ 与 pnpm（构建前端/安卓需要）。验证：终端输入 node -v 与 pnpm -v 能看到版本号。
  • 已拿到 richman-main 完整源码（含 apps/client、apps/server、packages/*、apps/harmonyos）。
  • 一个已备案的域名（可选但强烈推荐）：用于 HTTPS 与平台审核。没有也能先用服务器 IP 跑通联机。
  • ☐ 云服务器：腾讯云 / 阿里云「轻量应用服务器」2 核 2G 起（ friends 级流量足够），系统选 Ubuntu 22.04。年付约 ¥60–200。
  • ☐ Android Studio：打包 APK 用（仅 Android 上架需要）。官网 developer.android.com 免费下载。
  • ☐ DevEco Studio：鸿蒙打包与上架用（仅鸿蒙需要）。华为官网免费下载，首次会引导装 HarmonyOS SDK（API 11）。
  • ☐ 华为开发者账号：developer.huawei.com 注册并完成实名认证（个人/企业，企业需营业执照）。上架鸿蒙市场必须本人认证。
你本地已经做好的服务端云就绪改动（无需再改，了解即可）：
  • apps/server/src/server.ts 已新增 GET /healthz 健康检查接口——云平台/负载均衡探活用，返回 200 ok。
  • apps/server/src/production.ts 已改为 httpServer.listen(port, '0.0.0.0')——显式监听所有网卡，云上才能被外网访问。

2. 上云部署（服务端 · 实现全天候联机）

目标：让 apps/server 在云服务器上常驻运行，崩溃能自动重启，外网可访问。以下命令在云服务器的终端执行（不是你本机）。

1购买并登录云服务器

  • 在云厂商控制台购买「轻量应用服务器」，镜像选 Ubuntu 22.04 LTS，记下公网 IP（如 1.2.3.4）。
  • 在控制台「防火墙/安全组」放行端口：TCP 80、TCP 443、TCP 22，以及你服务要用的端口（默认 3000，见下面步骤 5）。
  • 本机打开终端，SSH 登录：ssh root@1.2.3.4（Windows 可用 PowerShell 或 PuTTY；密码在云控制台设置）。看到 root@xxxx:~# 即成功。

2在服务器安装 Node.js 与 pnpm

# （推荐）先切到 root，后面路径/命令与本文一致、不用每条加 sudo
sudo su -

# 安装 Node.js 20（NodeSource 官方源）——下面两条是【两条独立命令】，务必分开执行
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs

# 安装 pnpm（用 10 匹配项目的 packageManager 要求）
npm install -g pnpm@10

# 验证
node -v   # 应显示 v20.x 或更高
npm -v
pnpm -v   # 应显示 10.x
若你登录的是普通用户（提示符不是 root@ 而是 admin@ / ecs-user@ 之类）：① 最省事是执行 sudo su - 切成 root 再照做；② 或每条命令前加 sudo。注意 curl ... | bash - 和 apt-get install 是两条独立命令，不要拼成一行（拼成 bash -apt-get 会报 invalid option）。

3把代码放到服务器

二选一：

  • A. 用 Git（推荐，以后更新方便）：在服务器 git clone <你的仓库地址> 到 /root/richman-main。以后更新只需 git pull。
  • B. 手动上传：本机把 richman-main 压缩成 zip，用 scp / 宝塔 / 控制台文件管理传到服务器并解压。
cd /root/richman-main
ls            # 应看到 apps/  packages/  package.json 等

4安装依赖并构建

# 在仓库根目录
pnpm install

# 构建前端（产物在 apps/client/dist，服务端会同源托管它）
pnpm --filter @richman/client build

# 服务端构建（仅类型检查 tsc --noEmit，可跑可不跑；真正启动用 tsx 跑源码）
pnpm --filter @richman/server build
看到 apps/client/dist 目录生成即前端构建成功。服务端无需编译（build 仅是 tsc --noEmit 类型检查），由 tsx 直接运行源码。不要在根目录直接跑 pnpm build——它会先执行 release:check 可能报错；请按上面分包构建。

5用 pm2 让服务常驻 + 崩溃自启

# 安装 pm2 进程管理器
npm install -g pm2

# 在仓库根目录启动服务端（server 用 tsx 直接跑 TypeScript，无需编译）
cd /root/richman-main
pm2 start "pnpm --filter @richman/server start" --name richman

# 想换端口？在命令前加 PORT=（默认 3000，Caddy 反代也跟着改）
# PORT=8080 pm2 start "pnpm --filter @richman/server start" --name richman

# 设为开机自启
pm2 save
pm2 startup   # 按提示把输出的命令再执行一次
经核对实际 apps/server/package.json：start = tsx src/index.ts，服务端直接跑 TS 源码、不产出 dist，端口来自环境变量 PORT（默认 3000）。所以启动用 pnpm --filter @richman/server start，不要用 node dist/production.js 或 --port 参数那种方式。

验证进程：pm2 status 应显示 richman 状态 online。

6验证联机接口（健康检查）

curl http://localhost:3000/healthz   # 应返回 ok
curl http://1.2.3.4:3000/healthz     # 用公网 IP 也应返回 ok
外网能返回 ok 即说明部署成功。现在用手机/另一台电脑浏览器打开 http://1.2.3.4:3000 就能联机对战了（HTTP 下 WebSocket 也能用，但上架 App 建议走 HTTPS）。

7（推荐）用 Caddy 反代 + 免费 HTTPS

上架 App 时，云端模式务必用 HTTPS 地址（否则部分鸿蒙版本会拦截 WebSocket）。最省事是用 Caddy 自动申请证书。

# 安装 Caddy（Ubuntu）
apt-get install -y debian-keyring debian-archive-keyring apt-transport-https
curl -fsSL https://get.caddy.com | bash -

# 写配置：把你的域名指向服务器 IP 后
cat > /etc/caddy/Caddyfile <<'EOF'
richman.example.com {
    reverse_proxy localhost:3000
}
EOF

# 启动
caddy reload --config /etc/caddy/Caddyfile
# 或 systemctl restart caddy

把 richman.example.com 换成你已备案并解析到本服务器 IP 的域名。Caddy 会自动申请/续期 Let's Encrypt 证书。至此你的联机地址为 https://richman.example.com。

没有域名时：可先用 http://公网IP:3000 跑通联机；但此地址在部分手机系统上会被限制，正式上架建议配域名 + HTTPS。
上云部署完成标志：浏览器打开 https://你的域名（或 http://IP:3000）能看到大富翁首页，且两台设备能建房/加入并正常对战。记下这个地址，下一步打包 App 要填进去。

3. Android 打包（Capacitor → APK）

原理：用 Capacitor 把 apps/client/dist 网页包进一个原生 Android 外壳（WebView）。联机靠 WebSocket，WebView 原生支持，无需额外插件。下列命令在你本机执行（需 Node 20+、pnpm、Android Studio）。

1构建前端

cd richman-main/apps/client
pnpm build            # 产物生成在 apps/client/dist
云端模式可跳过打包网页进 APK（见步骤 3 的 server.url 说明）；离线模式必须把 dist 打进 APK，必须先 build。

2初始化并添加 Android 平台

# 首次：初始化 Capacitor（若已存在 capacitor.config.ts 可跳过）
pnpm cap:init

# 添加 Android 平台（会生成 android/ 原生工程目录）
pnpm cap:add:android

# 把网页构建产物同步进 Android 工程
pnpm cap:sync

脚本已写进 apps/client/package.json：cap:init / cap:add:android / cap:sync / cap:build:android。若提示找不到 cap 命令，先 pnpm add -D @capacitor/cli。

3（云端模式）告诉 App 从哪加载游戏

打开 apps/client/capacitor.config.ts：

const config: CapacitorConfig = {
  appId: 'com.richman.game',      // 上架用的唯一 ID，保持
  appName: '大富翁联机',
  webDir: 'dist',
  server: {
    // 云端模式：取消下面注释，改成你的云地址；APK 不再内置网页，永远加载线上最新版
    // url: 'https://richman.example.com',
  },
};
  • 云端模式：把 url 改成你的 https://...，取消注释 → 重新 pnpm cap:sync。
  • 离线模式：保持 url 注释掉，dist 会被打进 APK → 重新 pnpm cap:sync。

4用 Android Studio 打开并签名打包

  1. 打开 Android Studio → File → Open → 选择 richman-main/apps/client/android 目录。
  2. 等待 Gradle 同步完成（首次会下载依赖，可能几分钟）。
  3. 配置签名：Build → Generate Signed Bundle / APK → APK → 创建/选择 keystore（.jks）。keystore 密码与别名请牢记，以后更新包要用同一个。
  4. Build → Build Bundle(s) / APK(s) → Build APK(s)，等右下角提示 "APK(s) generated"。
  5. 点提示里的 locate，拿到 android/app/build/outputs/apk/release/app-release.apk。
也可在本机直接跑 pnpm cap:build:android 调起 Android Studio 的构建（仍需先在 Android Studio 配好签名）。流程以 Android Studio 点界面更直观，适合无经验人员。
Android 打包完成标志：得到 app-release.apk，手机安装后能打开并联机对战。

4. 鸿蒙打包（ArkTS Web 组件 → HAP / APP）

原理与 Capacitor 一样：原生外壳里跑 WebView，游戏逻辑全在网页端，原生层只负责全屏承载 + 联网权限。工程骨架已在 apps/harmonyos/（包名 com.richman.game）。下列在你本机 DevEco Studio 操作。

1用 DevEco 打开工程

  1. 安装并打开 DevEco Studio，首次会引导安装 HarmonyOS SDK（API 11）。
  2. File → Open → 选择 richman-main/apps/harmonyos。若打开报错/缺资源，改用 DevEco 新建 Empty Ability 工程，再把本目录的 EntryAbility.ts、Index.ets 覆盖进新工程即可。
  3. 补图标：工程需 entry/src/main/resources/base/media/startIcon.png。新建工程会自动生成，用本骨架则请补一张，否则编译报资源缺失。

2决定游戏从哪加载（云端 / 离线）

打开 apps/harmonyos/entry/src/main/ets/pages/Index.ets：

const SERVER_URL: string = 'https://richman.example.com';
// 云端模式：保持 .src(SERVER_URL)，把上面的地址改成你的云地址
// 离线模式：把 apps/client/dist 整目录复制到 entry/src/main/resources/rawfile/，
//           然后把 .src(SERVER_URL) 改为 .src($rawfile('index.html'))
  • 云端模式（推荐）：把 SERVER_URL 改成你的 https://...，保持 .src(SERVER_URL)。服务端更新即生效，无需发版。
  • 离线模式：复制 dist 到 rawfile/，改成 .src($rawfile('index.html'))。玩家不联网也能开首页（联机仍需网）。
云端模式务必用 HTTPS 地址，否则部分鸿蒙版本会拦截 WebSocket 连接。

3真机调试（先验证能跑）

  1. 手机开「开发者模式 → USB 调试 / 无线调试」，数据线连电脑。
  2. DevEco 顶部选设备，点 ▶ Run。首次需签名：File → Project Structure → Signing Configs，勾「Automatically generate signature」并登录华为账号，自动生成调试证书。
  3. 手机上应能看到全屏的大富翁并能联机。

4打包 Release APP（上架用）

  1. 上架前打 Release：Build → Build Apps → Build APP，产出 .app（App Pack，内含 HAP）。
  2. Release 必须用发布证书签名：Project Structure → Signing Configs → Release，导入从 AppGallery Connect 下载的 .p12 证书 + .cer + Profile（见第 5 节先去申请三件套，再回这里打包）。
  3. 产物位置：apps/harmonyos/build/outputs/ 下的 *.app。
本地调试用 Build → Build Hap(s) → Build Debug Hap 出 HAP 即可，不必走发布证书。
鸿蒙打包完成标志：得到 *.app 文件，准备进入上架流程。

5. 鸿蒙应用市场上架（AppGallery Connect）

必须本人操作：账号实名认证、支付、平台提交审核均无法代劳。下面清单逐条照做即可独立完成。

1华为开发者联盟实名认证

  1. 打开 developer.huawei.com → 注册并登录。
  2. 进入「管理中心 / 实名认证」：个人选个人认证（刷脸/银行卡），企业选企业认证（需营业执照）。按页面提示完成。
  3. 认证通过后才能创建应用与申请发布证书。

2在 AppGallery Connect 创建应用

  1. 打开 AppGallery Connect → 「我的应用 → 新建应用」。
  2. 填写：应用名称「大富翁联机」、包名 com.richman.game（必须与工程一致）、分类 游戏/桌游、支持设备 手机+平板。
  3. 创建后进入应用详情页，记下应用对应的 APP ID。

3申请"证书、APP ID、Profile"三件套（发布签名必需）

  1. 证书（.cer + .p12）：用户与访问 → 证书管理 → 新增证书，类型选发布证书，下载得到 .cer 和生成时的 .p12（p12 密码自己设，牢记）。
  2. APP ID（应用标识）：在第 2 步已创建，我的应用 → 对应应用 → 应用信息 里查看。
  3. Profile（.p7b）：我的应用 → 对应应用 → 添加证书（发布） 关联第 3.1 的发布证书，生成并下载 .p7b Profile 文件。
三件套对应关系：发布证书(.cer/.p12) + APP ID + Profile(.p7b)。回到第 4 节步骤 4，在 DevEco 的 Release 签名里导入这三者后再 Build APP。

4填写上架资料并上传

  1. 在应用详情页「上架」流程填写：应用介绍、一句话简介、隐私政策网址（需自备一个可访问的隐私政策页面）、应用截图（手机 + 平板各若干张，按平台尺寸要求）。
  2. 若游戏涉及版号/备案等资质，按平台提示上传（休闲单机/联机小游戏通常按平台指引填"不适用/未涉及"，以平台审核意见为准）。
  3. 上传第 4 节打出的 *.app 文件。

5提交审核与发布

  1. 「提交审核」。审核通常 1–3 个工作日，留意短信/邮件/站内信。
  2. 若被打回，按审核意见修改（多为截图/隐私政策/资质问题），改完重新提交。
  3. 审核通过后点「发布」，应用即上架华为应用市场，用户可搜索「大富翁联机」下载。
鸿蒙上架完成标志：华为应用市场能搜到「大富翁联机」，下载安装后可联机对战。

6. Android 市场上架（可选）

Android 上架非必须（APK 可直接发给朋友安装）。若要上架：

  • 应用宝（国内）：注册腾讯开放平台开发者，上传第 3 节得到的 app-release.apk，填资料 + 软著/资质（按平台要求），审核发布。
  • Google Play（海外）：注册 Google Play Console（需 $25 一次性注册费），创建应用、上传 AAB（Build → Generate Signed Bundle → Android App Bundle），填商店资料与隐私政策，发布。
应用宝/Google Play 对隐私政策、权限声明、软著等有明确要求，按平台指引准备即可，与鸿蒙上架思路一致。

7. 发布检查清单

发布前逐项确认（☐ 打勾）：

  • ☐ 云服务器已运行，/healthz 外网返回 ok
  • ☐ 浏览器打开云地址能建房/加入并正常对战
  • ☐ 已决定云端/离线模式，且 App 配置里的地址已改对（云端模式必须是 HTTPS）
  • ☐ Android：已 pnpm build + cap:sync，Android Studio 签名出 app-release.apk
  • ☐ 鸿蒙：DevEco 用发布证书三件套签名出 *.app
  • ☐ 华为开发者账号已实名认证
  • ☐ AppGallery Connect 已建应用（包名 com.richman.game），证书/APP ID/Profile 三件套齐全
  • ☐ 上架资料齐全：应用介绍、隐私政策网址、手机+平板截图
  • ☐ 真机验证：Android 与鸿蒙各一台，能跨端联机对战
  • ☐ 已知会：服务器重启会丢失进行中牌局（当前代码无持久化）

8. 常见问题与排错

现象可能原因处理
