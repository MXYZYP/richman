# M3-1 静态棋盘 UI 设计（热座版第一切片）

目标：先让浏览器真实渲染出可评审的棋盘骨架，不接掷骰/买地/盖房交互。数据全部来自 `board.json` + 固定 3 人 `createGame` state：61 格（52 外环 + 9 支线）、3 个玩家头像/现金/bot 标识、棋子位置与同格错位。验收以 1440×900 与 390×844 截图为准。

## 布局与组件

- `App.vue`：固定创建 3 人测试局，进入棋盘页；开局设置页留到 M3 后续。
- `GameBoard.vue`：棋盘容器，包含外环层、支线层、中央骰子/事件提示占位、棋子层。
- `BoardCell.vue`：单格显示；桌面显示色带/名称/价格，手机降级为色带 + 短名/图标（价格等细节后续点格弹卡）。
- `PlayerRail.vue`：3 个玩家资产条，显示头像色、形状记号、现金、bot 标识，数据来自真实 `GameState.players`。
- `ActionPanel.vue`：占位操作面板，不接规则；用于验证 02 §4.4 的手机/桌面空间。

## 52 外环格映射：14×14 Grid 环

14×14 的边框格刚好是 52 格。按实体方位：起点右下角，机场左下角，兰州牛肉面左上角，维港右上角，顺时针走。坐标为 1-based `row/col`：

| cell id | grid 位置 |
|---|---|
| 0 起点 | `(14,14)` |
| 1–12 | 底边，从右到左：`row=14, col=13..2` |
| 13 机场 | `(14,1)` |
| 14–25 | 左边，从下到上：`col=1, row=13..2` |
| 26 兰州牛肉面 | `(1,1)` |
| 27–38 | 顶边，从左到右：`row=1, col=2..13` |
| 39 维港 | `(1,14)` |
| 40–51 | 右边，从上到下：`col=14, row=2..13`，51 后回 0 |

实现上只写映射公式，不写格子名称/价格；内容全部由 `boardData.cells[id]` 渲染。

## 支线与中央信息共存

支线 52–60 作为 `branch-layer` 绝对定位在棋盘中央，对角线从 13 机场指向 40 黑龙江：`13 机场 → 52 首尔 → 53 东京 → 54 机会 → 55 纽约 → 56 伦敦 → 57 巴黎 → 58 命运 → 59 曼谷 → 60 河内 → 40 黑龙江`。中央骰子/事件提示是半透明小面板，位于棋盘中心；支线格用较小圆角卡片沿对角线排列，z-index 高于中央面板，确保走向可辨认。

草图（非比例）：

```text
┌ 26 兰州 ───── 顶边 27..38 ───── 39 维港 ┐
│                                             │
│                                  40 黑龙江  │
│                         60 河内 ↗          │
│                  57 巴黎 / 58 命运 / 59曼谷 │
│        [ 中央：骰子 + 当前事件提示，占位 ]   │
│          52 首尔 / 53 东京 / 54 机会 / 55纽约│

```

手机 390px 下，棋盘占满宽度；外环格内容降级为短名/图标，保证裸眼可读，不做缩放。桌面 ≥768px 下左棋盘右侧栏；手机下按 02 §4.4：玩家条 → 棋盘 → 操作面板 → 最近日志占位。
