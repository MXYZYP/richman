# M3-8 Game Setup Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the fixed demo start with a real local setup screen where the user chooses 2-4 players, at least one human, nicknames, and optional cash goal before entering the board.

**Architecture:** Keep the rule engine unchanged. Add a client-only setup model that converts setup form state into `createClientGame()` input. Add a Vue setup component and make `App.vue` switch between setup mode and active game mode without affecting existing board/action/asset/cell-detail components.

**Tech Stack:** Vue 3 Composition API, TypeScript, Vitest, existing `@richman/engine`/`@richman/board-data` packages.

```ts
import { describe, expect, it } from 'vitest';
import {
  createDefaultGameSetup,
  gameSetupToCreateOptions,
  updateGameSetupCounts,
  validateGameSetup,
} from './gameSetup';

describe('game setup model', () => {
  it('defaults to one human and two bots', () => {
    const setup = createDefaultGameSetup();
    expect(setup.humanCount).toBe(1);
    expect(setup.botCount).toBe(2);
    expect(setup.players.map((player) => player.isBot)).toEqual([false, true, true]);
  });

  it('keeps total players between 2 and 4 while preserving human minimum', () => {
    let setup = createDefaultGameSetup();
    setup = updateGameSetupCounts(setup, { humanCount: 0, botCount: 4 });
    expect(setup.humanCount).toBe(1);
    expect(setup.botCount).toBe(3);
    expect(setup.players).toHaveLength(4);

    setup = updateGameSetupCounts(setup, { humanCount: 1, botCount: 0 });
    expect(setup.humanCount + setup.botCount).toBe(2);
  });

  it('converts valid setup into createClientGame options', () => {
    const setup = createDefaultGameSetup();
    setup.players[0].nickname = '阿明';
    const result = validateGameSetup(setup);
    expect(result.ok).toBe(true);

    const options = gameSetupToCreateOptions(setup);
    expect(options.players).toEqual([
      { id: 'p1', nickname: '阿明', isBot: false },
      { id: 'p2', nickname: '电脑A', isBot: true },
      { id: 'p3', nickname: '电脑B', isBot: true },
    ]);
    expect(options.cashGoal).toBe(null);
  });

  it('rejects cash goal that is lower than or equal to initial cash', () => {
    const setup = createDefaultGameSetup();
    setup.cashGoalEnabled = true;
    setup.cashGoal = 30000;
    expect(validateGameSetup(setup).ok).toBe(false);
  });
});
```

- [ ] **Step 3: Implement minimal setup model**

Implement types and functions:

```ts
export interface GameSetupPlayer {
  id: string;
  nickname: string;
  isBot: boolean;
}

export interface GameSetupForm {
  humanCount: number;
  botCount: number;
  players: GameSetupPlayer[];
  cashGoalEnabled: boolean;
  cashGoal: number;
}

export function createDefaultGameSetup(): GameSetupForm;
export function updateGameSetupCounts(setup: GameSetupForm, counts: { humanCount?: number; botCount?: number }): GameSetupForm;
export function validateGameSetup(setup: GameSetupForm): { ok: true } | { ok: false; message: string };
export function gameSetupToCreateOptions(setup: GameSetupForm): CreateClientGameOptions;
```

Rules:
- Total players: 2-4.
- Humans: 1-4.
- Bots: 0-3.
- Default: 1 human + 2 bots.
- Default human names: `玩家一`, `玩家二`, `玩家三`, `玩家四`.
- Default bot names: `电脑A`, `电脑B`, `电脑C`.
- `cashGoalEnabled=false` maps to `cashGoal:null`.
- Enabled cash goal must be `> gameConfig.initialCash`.
