# M3-9 BOT Auto Action Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let local BOT players automatically choose and send legal actions with a random 0.8-1.6 second delay until a human turn or game over.

**Architecture:** Reuse the existing engine `chooseBotIntent` strategy. Keep autoplay inside `clientGame.ts`, where state, animation, delays, and `sendIntent` already live. App enables autoplay; direct tests keep it off unless explicitly enabled.

**Tech Stack:** Vue 3 Composition API, TypeScript, Vitest, existing `@richman/engine` bot strategy.

- [ ] **Step 4: Schedule BOT actions**

```ts
async function runBotTurnIfNeeded() {
  if (!autoPlayBots || isAnimating.value || isBotThinking.value || state.value.phase === 'game_over') return;
  const actor = actorOf(state.value);
  if (!actor?.isBot) {
    consecutiveBotActions = 0;
    return;
  }
  if (consecutiveBotActions >= 20) {
    lastError.value = '电脑自动行动次数过多，已暂停';
    return;
  }

  isBotThinking.value = true;
  eventMessage.value = `电脑思考中：${actor.nickname}`;
  await wait(botDelay());
  isBotThinking.value = false;

  const latestActor = actorOf(state.value);
  if (!latestActor?.isBot || state.value.phase === 'game_over') return;
  consecutiveBotActions += 1;
  await sendIntent(chooseBotIntent(state.value, latestActor.id), { automated: true });
}
```

After successful `sendIntent`, call:

```ts
void runBotTurnIfNeeded();
```

At create time, if `autoPlayBots` is enabled:
