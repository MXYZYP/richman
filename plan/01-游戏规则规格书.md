# 01 · 游戏规则规格书（官方银牌规则定案版）

> **本文档是游戏规则的唯一权威来源。** 依据 owner 提供的官方说明书原文（[plan/assets/官方说明书-银牌.md](assets/官方说明书-银牌.md)）、两份官方地皮数据（`raw/大富翁-普通地皮.md`、`raw/大富翁-非普通地皮.md`）与 owner 整理的卡牌文字版（`raw/机会卡.md`、`raw/命运卡.md`）编写。
>
> - **重要**：本游戏是"银牌"系中国规则，与美版标准 Monopoly 差异很大——**没有色组、没有双数加掷、没有拍卖；盖房靠"停留在自己地产上"；地产可半价卖回银行；出狱靠掷出 10 点以上**。执行 agent 不得把标准 Monopoly 的常识带进实现。
> - **§14 开放问题已全部关闭，本规格书定稿（2026-07-05）**，阶段 1 引擎开发可以开工。实现中再遇规则疑义按 00 §7 第 8 条处理（先查本文档，文档没写的问 owner，结论回填）。

## 1. 术语表

| 中文 | 英文（代码用） | 含义 |
|---|---|---|
| 格子 | cell | 棋盘上的一格，`id` 从 0（起点）沿**顺时针**行进方向递增 |
| 地产 | property | 可购买的格子；子类型见 §6.1 |
| 过路费 | toll / rent | 停留他人地产时支付的费用（代码沿用 rent 命名） |
| 盖房等级 | level | 0=空地，1-4=房屋数，5=旅馆（第五幢换旅馆） |
| 抵押 | mortgage | 把地产押给银行换现金，期间不收过路费 |
| 出狱许可证 | jail card | 抽到可保留，也可向他人出售（价格自议） |
| 银行 | bank | 系统资金方（无限资金），非玩家 |
| 债务状态 | debt state | 应付金额超过现金，进入强制筹款流程 |
| 现金目标 | cash goal | 官方提前结束玩法：现金先达标者胜（说明书第十二条） |

## 2. 全局配置数值（`game-config.json` 字段）

> 原则调整：规则**机制**按本文档直接实现（不再做"标准版/实体版"双轨开关）；进 config 的只是**数值**，便于微调。

| 字段 | 含义 | 定案值 | 依据 |
|---|---|---|---|

| `maxHouseLevel` | 盖房等级上限（5=旅馆） | **5** | 说明书五 |
| `sellHouseRefundRate` | 卖房返还比例（相对单栋建筑费） | **0.5** | 说明书十 |
| `sellLandRate` | 无房地产卖回银行比例（相对地价） | **0.5** | 说明书十 |
| `mortgageInterestRate` | 赎回时按贷款金额加收的利息 | **0.1** | 说明书九 |
| `utilityMultipliers` | 特殊地皮过路费倍数（持有 1 处 / 2 处全有） | **[10, 100]** | 非普通地皮数据 |
| `jailExitMinRoll` | 出狱所需最小点数（监狱模块参数，本版模块关闭） | **10**（含） | 说明书八 |

| `airportBranchDice` | 机场支线再掷的骰子颗数 | **1**（一颗骰子 1-6，K13 补充定案 2026-07-06） | owner 确认 |
| `jailEnabled` | 本棋盘是否有监狱玩法 | **false**（定案 K1：中国之旅银牌棋盘无监狱格；未来地图可启用，见 §8） | owner 确认 |

金额一律为**整数**；比例计算结果四舍五入取整，引擎全局统一用同一个取整函数（本套数值下通常整除）。

## 3. 开局

1. 2-4 名玩家（真人 + 电脑玩家合计，真人至少 1 名；电脑玩家与真人遵守**完全相同**的规则，本文档一切条款对两者一视同仁），每人领 `initialCash`，棋子放起点（cell 0）。
2. **决定顺序**：每人掷一次，点数多者先行（说明书二）；电子版实现为开局自动依次掷骰展示点数并排序（同点数者复掷）。
3. 若房主开启**现金目标**房规，开局前设定目标金额（预设 30000/50000，可自定）。

## 4. 单回合流程（回合状态机）

**没有双数加掷、没有三连双入狱**（说明书通篇无双数规则）。每人每回合正常掷一次、走一次、结算一次、做完财务操作即交棒；机场支线是例外：停留机场后同一回合等待玩家再掷一颗支线骰。

```
（awaiting_jail_decision：监狱模块阶段，本版关闭不出现，见 §8）

awaiting_roll → [自动结算 resolving]
     → 停留机场：awaiting_airport_roll（再掷一颗支线骰，见 §5.1）
     → 落无主地产：awaiting_buy_decision（买 / 放弃）
     → 落自己地产：awaiting_build_decision（盖一幢 / 跳过，见 §6.3）
     → 落他人地产 / 功能格：自动结算
     → managing（卖房、卖地；阶段 3 起还有抵押、赎回，然后结束回合）→ 下一位
```

| 阶段 | 谁操作 | 允许的操作（intent） |
|---|---|---|
| `awaiting_jail_decision` | —（本版不出现：监狱模块关闭，§8） | 掷骰尝试出狱 / 使用出狱许可证 |
| `awaiting_roll` | 当前玩家 | 掷骰（两颗骰子，点数和 2-12，K2 定案） |
| `awaiting_airport_roll` | 当前玩家 | `roll_airport_branch`（一颗骰子，首尔为第 1 步） |
| （resolving，引擎自动） | — | 移动、落点结算、发卡牌效果，产生事件流 |
| `awaiting_buy_decision` | 当前玩家 | `buy_property` / `skip_buy`（现金不足时只能放弃） |
| `awaiting_build_decision` | 当前玩家 | `build_house` / `skip_build`（条件见 §6.3） |
| `managing` | 当前玩家 | 卖房、卖地、（阶段 3：抵押、赎回）、结束回合 |
| `game_over` | — | 全局 phase（见 03 §4.1），展示结算画面 |
| （任意阶段可插入）债务状态 | 欠债玩家 | 卖房、卖地、（阶段 3：抵押）、宣告破产（§11） |

### 4.1 经过起点

棋子**经过或停留**起点，从银行领 2000（说明书三，经过与停留同酬，无额外奖励）。判定：本次移动位置编号发生绕回。跳跃式移动（卡牌/支线的 `move_to`）同理，官方口径已由卡面文字给出：**"前进至 X"经过起点领 2000**（命运卡 71-24 明示"如经过起点，可得奖金 2000 元"）；**"退回起点"不领**（首尔格与命运卡 71-25 均明示）。卡组已全部转录：**没有"后退 N 步"卡**（K11），无需定倒退口径。

| `property` | 地产（普通 / 火车站 / 特殊地皮） | 见 §6 |
| `chance` / `destiny` | 机会 / 命运 | 抽对应牌堆顶一张，展示并立即生效，用毕放回**堆底**（§9） |

> 棋盘布局已**全部转录并经 owner 确认**（见 [plan/assets/棋盘数据核对表.md](assets/棋盘数据核对表.md)）：**外环 52 格**（四角：起点、机场、兰州牛肉面、维多利亚港；地产 41 块与地皮数据零冲突；机会×3、命运×3、所得税×1）**+ 对角线"环游世界"支线 9 格**（id 52-60），共 61 格。引擎与 UI **不得写死格数与形状**。

### 5.1 环游世界支线（本棋盘特有结构，说明书未记载）

棋盘不是单一环形：左下角**机场**通过一条对角线支线（韩国首尔→日本东京→…→越南河内，共 9 格）连回外环。规则依据：印在棋盘格子上的文字 + owner 口述玩法（2026-07-05，K13/K14 定案；说明书全文没有提及机场与支线）。

- **走法（K13/K15 定案，2026-07-07 owner 调整触发节奏）**：停留机场后**同回合等待玩家再掷一颗骰子（1-6；注意只用一颗，与环上正常移动的两颗不同）**，**第一步踏上首尔**——掷 1 落首尔、掷 2 落东京、……掷 6 落巴黎。只有"停留"机场才触发，移动途中经过机场不触发。支线尽头河内(id 60)之后接**黑龙江省(id 40)**：支线内的**效果移动**（东京"前进五步"、巴黎"前进一步"、卡牌"前进三步"等）越过河内时自然走上外环。支线不经过起点；支线上的跳转效果按 §4.1 口径处理。
- 按此走法的客观事实（实体棋盘自身特性，**照实现即可，不要"修正"**）：机场一掷最远到巴黎；命运格(58)靠东京/巴黎的效果到达；曼谷(59)/河内(60)只会被效果移动路过、不会被正好踩中。
- 移动模型：棋盘是"每格指向下一格"的**有向图**（外环成环 + 支线为岔路），引擎按图行走、完全数据驱动（见 03 §4 与 02 §2.1 的 `nextId`/`branchEntryId`）——这也天然满足 owner 的模块化需求（换任何形状的棋盘都只是换数据）。
- 支线格（`world`）均为效果格：落格执行格上文字（退回起点、前进 N 步、付款/收款、暂停等），用 §9 的效果枚举表达；9 格的原文与映射见核对表表 A2。

## 6. 地产

### 6.1 子类型与过路费

| `subtype` | 数据来源 | 过路费规则 |
|---|---|---|
| `normal`（普通地皮，35 块） | `raw/大富翁-普通地皮.md` | 按盖房等级查 `rents[level]`（长度 6：空地/1-4 房/旅馆）。**没有色组，没有"集齐翻倍"** |
| `station`（火车站，4 块） | `raw/大富翁-非普通地皮.md` | 按所有者持有车站数查 `rents[持有数-1]`：250/500/1000/2000。不可盖房 |
| `utility`（特殊地皮：中国大运河、大唐托克托发电厂） | 同上 | 过路费 = **踩上者当次掷骰点数** × 倍数（持有 1 处 ×10；两处全有 ×100）。不可盖房 |

例外不收费：地产**抵押中**（说明书九）；停自己地产不付费（转为盖房决策，§6.4）。

### 6.2 购买

停留无主地产可按 `price` 购买（现金不足不可选）。放弃则保持无主，**无拍卖**。被卖回银行的地产（§6.5）重新变为无主，可再购买。

### 6.3 盖房与旅馆（本版本核心特色）

- **唯一盖房时机：停留在自己的地产上**（说明书四）。每次停留至多盖**一幢**：支付该地 `houseCost`（单栋房屋/旅馆同价，见数据），等级 +1。
- 等级上限 5：第五次盖时同样支付 `houseCost`，标志由 4 幢房屋换为**一幢旅馆**（说明书五）。
- 不需要集齐任何组合，无均匀建房约束。火车站与特殊地皮不可盖房。
- 停留在自己**抵押中**的地产上**不可盖房**，须先赎回（K8 定案）。

### 6.4 卖房（说明书十）

- 时机：自己回合 `managing` 阶段或债务状态中，随时、逐幢。
- 每卖一级返还 `houseCost × 0.5`。旅馆视同 5 幢房屋逐幢出售（等级 5→4 返还半价一幢，依此类推）。

### 6.5 卖地（说明书十，标准 Monopoly 没有的规则）

- **无房**且**未抵押**的地产，可按 `price × 0.5` 卖回银行；卖出后变无主。
- 时机同卖房。抵押中的地产不可出售。

## 7. 抵押与赎回（说明书九）

- 任何**无房**地产可随时抵押（本版本无色组，无组内约束），所得为该地 `mortgageValue`（官方数据 = 地价一半，两份地皮文件已给全）。
- 抵押期间不收过路费，且**不计入"持有数"计费档**（K8 定案）：车站计数与特殊地皮"两处全有"判定只数**未抵押**的。例：持有 3 个车站、其中 1 个抵押中 → 他人踩到你未抵押的车站按"2 个车站"档收费；两处特殊地皮全有但其一抵押中 → 另一处按 ×10 收。
- 赎回随时可为：支付 `mortgageValue × 1.1`（贷款金额 + 10% 利息）。

## 8. 监狱（可选规则模块：本版关闭，规格保留）

**K1 定案：中国之旅（银牌）棋盘无监狱格，本模块第一版不写任何代码**（引擎不建相关字段与阶段，出狱许可证类卡牌也不应出现在本版卡组——转录时交叉验证）。

本节保留为**未来新地图**的模块规格（owner 已明确希望模块化：换地图时改数据即可，新机制按保留规格扩展，见 00 §4 决策 5 与 03 §4 的扩展点说明）。未来某张地图含"进牢"格并将 `jailEnabled` 设为 true 时，按下述实现：

- **入狱**：① 停在"进牢"格；② 抽到"进牢"卡。棋子移至监狱角格（不经过起点、不领报酬金），回合立即结束。
- **狱中**：不移动。默认可照常收过路费与做财务操作（说明书未禁止；启用模块时与 owner 确认）。盖房天然不可能（盖房需要"停留"）。
- **出狱**（每回合 `awaiting_jail_decision`）：
  1. 掷骰：点数 ≥ **10** → 立即出狱；是否按该点数移动：**默认移动**（启用模块时与 owner 确认）；未达 10 → 本回合结束，已尝试次数 +1；
  2. 使用出狱许可证 → 立即出狱，本回合正常掷骰移动；出狱卡归还其来源牌堆堆底；
  3. 三次尝试用尽后的处理：说明书未写，**默认第四回合起自动出狱（正常掷骰移动）**（启用模块时与 owner 确认）。
- **没有保释金机制**（说明书没有，不实现）。

## 9. 机会与命运卡

- 两个独立牌堆（本版无"欢乐卡"——那是上海滩款），开局各自洗乱；抽顶、生效、放回**堆底**。
- 出狱许可证例外：翻阅者保留，可使用或**向他人出售（价格自议）**（说明书六/八）——**已验证：本版 30 张卡中无出狱/进牢卡**（与 K1 互证 ✅）。
- 卡面内容已全部转录：**机会 15 张 + 命运 15 张**（原文与逐张效果映射见核对表表 B，来源 `raw/机会卡.md`、`raw/命运卡.md`）。效果用统一枚举表达（`go_to_jail` 与 `get_out_of_jail_free` 为监狱模块保留项，本版卡组中不出现）：

| `effect.type` | 参数 | 含义 |
|---|---|---|
| `move_to` | `cellId`, `collectSalary` | 移动到指定格（默认经过起点领报酬金），到达后照常结算落点 |
| `move_steps` | `steps`（可为负） | 前进/后退 N 格，到达后照常结算 |
| `pay_bank` / `receive_bank` | `amount` | 与银行收付 |
| `pay_each_player` / `receive_from_each_player` | `amount` | 与其他每位在场玩家收付 |
| `go_to_jail` | — | 进牢（仅当监狱模块启用） |
| `get_out_of_jail_free` | — | 获得出狱许可证 |
| `repairs` | `perHouse`, `perHotel` | 按名下房屋幢数与旅馆数缴费给银行 |
| `skip_turn` | `turns`（默认 1） | 暂停 N 个回合（轮到时自动跳过并计数减一）——两个角格与支线"暂停"格也用它（河内为 turns=2） |
| `draw_card` | `deck`（`chance`/`destiny`） | 立即再从指定牌堆抽一张并生效（命运卡 71-30"参观兵马俑，可再翻一张机会"） |
| `none` | — | 无数值效果，仅展示卡面让大家乐一下（命运卡 71-20"每人给予鼓掌十下"） |
| `custom` | `description` | 无法归类的卡：原文记录，owner 确认玩法后单独实现——**转录已确认本版 30 张卡全部可用上述枚举表达，无 custom 卡** |

## 10. 玩家间交易（本版不实现；规格保留）

**K3 定案：严格按说明书**——玩家间唯一可交易物是出狱许可证（自议价）；而 **K1 定案本棋盘无监狱 ⇒ 无出狱许可证 ⇒ 本版没有任何玩家间交易功能**。地产只与银行往来（买、卖、抵押）。

以下保留为未来含监狱地图的模块规格：出狱卡持有者在自己回合 `managing` 阶段发起，指定对象与价格 → 对方接受/拒绝 → 接受即钱卡两讫；一次只能有一个进行中的提议。

## 11. 现金不足与破产（说明书十一）

应付金额 > 现金时进入**债务状态**：

1. 冻结当前流程；欠债玩家可**卖房、卖地**（阶段 3 起还有：抵押）筹款；
2. 现金一旦足额必须立即支付，流程恢复；
3. 变现手段用尽仍不足（判定：现金 + 全部房屋折卖 + 全部无房未抵押地产半价 + 阶段 3 的可抵押价值 < 应付金额），或玩家主动宣告破产：
   - 剩余现金**全数交给债主**（债主为玩家或银行，说明书十一）；
   - 名下地产**一律变回无主**（K4 定案）：房屋消失、抵押注销，任何人此后停留可再购买——无论债主是玩家还是银行，处理一致；
4. 破产者出局，棋子移除，轮到其回合时自动跳过。

## 12. 胜利条件

- **标准结局**：最后一位未退出者为"大富翁"（说明书十一）。
- **现金目标房规**（官方，说明书十二）：开房时可开启并设定金额（预设 30000/50000）；任何玩家**手上现金**（不含地产价值）达到目标即立即获胜。判定时点：任意导致现金增加的结算完成后。**自定目标金额必须大于初始资金**（`createGame` 在 `cashGoal !== null && cashGoal <= config.initialCash` 时抛错）。
- 结算画面展示：胜者、各玩家最终现金与地产清单、存活回合数（破产玩家记录出局回合 `bankruptTurn`，即宣告破产时的回合计数）。
